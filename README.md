# Aayush-Portfolio

> **AAYUSH // THE WORKSHOP** — Interactive digital workshop showcasing Agentic AI architectures, autonomous agents, and modern full-stack systems.

---

## 🚀 Features

- **Interactive 2.5D Digital Engineering Lab**: Dynamic interactive workshop with ambient lighting, spatial UI, and immersive soundscapes.
- **Agentic AI & Full-Stack Projects**: Direct access to production-grade AI agents, developer tools, and web applications.
- **Interactive Terminal & Agent Chat**: Embedded interactive prompt interface for testing and interacting with AI systems.
- **Modern Responsive Design**: Built with React 19, TypeScript, and Vite with custom cyberpunk & sleek glassmorphic aesthetics.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Vanilla CSS, Glassmorphic UI tokens, Canvas Confetti
- **Icons**: Lucide React
- **Audio**: Web Audio API Sound Effects

---

## 💻 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Aayush-Ash/Aayush-Portfolio.git

# Navigate to project directory
cd Aayush-Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
